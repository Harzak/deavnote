## Features

- Track time spent on development tasks
- Export work summaries quickly for tasks, days, or weeks
- Useful for daily reporting and activity summaries
- Lightweight integrated todo list
- Customizable export templates

## Built with

- .NET 10 (C#), MVVM
- Avalonia 12 ([Avalonia](https://github.com/AvaloniaUI/Avalonia))
- LiveMarkdown.Avalonia ([LiveMarkdown.Avalonia](https://github.com/DearVa/LiveMarkdown.Avalonia))
- Entity Framework Core (Sqlite)
